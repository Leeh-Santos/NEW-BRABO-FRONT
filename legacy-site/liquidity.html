Liquidity Manager

Community-driven liquidity provision for the $BRB/ETH pool

How It Works

80% of every ETH funding is automatically allocated to a batch fund. When the batch reaches the minimum threshold (0.02 ETH), anyone can call the "Add Liquidity" function to deposit these funds into the Uniswap V3 $BRB/ETH pool. This helps strengthen the liquidity, reduce slippage, and improve trading conditions for everyone.

Permissionless - Anyone can add liquidity
Transparent - All actions on-chain
Beneficial - Strengthens $BRB trading
